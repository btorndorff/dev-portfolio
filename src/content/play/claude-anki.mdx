I restarted learning Vietnamese back in the fall and realized I was pampered by Japanese which has a cornocopia of learning resources to pick from. For Vietnamese I simply wanted a top 1000 most common words anki deck with example sentences and audio but to my dismay there was nothing close. The thought of trying to understand and manually build that anki deck from scratch left me with dread so instead I looked to how an agent could help me with this.

A fun realization after working on agents for the past year has been <a href="https://zarazhang.substack.com/p/coding-agents-are-general-agents">coding agents are general agents</a> and they map perfectly to the task of managing an anki deck. I created a project for my claude code agent with specific prompting, skills, and mcps allowing it to fully run my Vietnamese deck for me. Here's an overview of how it works:

## System Prompt & USER.md

Coding agents like claude code ship with some default prompting on their purpose from their providers which usually entails specific directives about being a coding agent. My system prompt defined in <File>CLAUDE.md</File> overrides this and explains to the agent its new responsibilites of managing a language learing anki deck. The system prompt also has a fun piece of context that allows the agent to know exactly what card I'm on:

```
Current card: !`curl -s localhost:8765 -X POST -d '{"action": "guiCurrentCard", "version": 6}' 2>/dev/null | python3 -c "import sys,json; d=json.load(sys.stdin); r=d.get('result'); fields=r.get('fields',{}) if r else {}; parts=[f'{k}={v[\"value\"]}' for k,v in fields.items() if v.get('value')]; print(' | '.join(parts) if parts else 'No card open')" 2>/dev/null || echo "Anki not running"`
```

I also have a <File>USER.md</File> file that gets inlined in <File>CLAUDE.md</File> containing personalized info about my language learning and anki preferences. This ranges from the language, accent, and goals I have for vietnamese to the way I like my cards to be setup. heres an example of one of the rules:

```
- When constructing example sentences, prefer using vocabulary from existing cards in the deck rather than introducing new unknown words
```

## Anki connect & an anki-connect skill

The crux of this setup is the agent needs some way to interact with anki to manage cards and decks. Thankfully <a href="https://ankiweb.net/shared/info/2055492159">Anki Connect</a> is a plugin that allows applications to interact with anki using a simple HTTP API. Pairing this with an `anki-connect` skill that contains the full api reference + common workflows allows the agent to wield this API and use anki better than I ever could.

## Elevenlabs MCP

My language learning cards would be useless without audio for them so I added the Elevenlabs MCP to allow the agent to generate all of them for me. I found a voice + stability/speed settings I liked for Vietnamese and added that to the <File>USER.md</File> so it knows what to use when creating cards. I pay $5 a month for Elevenlabs and haven't run into any limiting issues so far.

I've been using this setup for a few months now and its absolutley changed my language learning. The future of language learning (and learning in general) is being able to have the right materials and the tools personalized to you and agents are the perfect medium for that.
